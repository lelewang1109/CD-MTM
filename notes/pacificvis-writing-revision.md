## 审稿定位

本稿适合定位为有形式化保证的可视化技术论文。主张是：计算不可避免的位置误差，
指出冲突特征，并报告换取位置改善所付出的合并层级代价。当前证据能够支持算法和几何
权衡；尚不能支持“用户读图更准确”“地理距离普遍更忠实”或“方法全面优于 ST-MTM”。

已核查 [2027 官方投稿指南](https://pacificvis2027.github.io/contribute/paper-submission-guidelines/)：
Conference Track 使用 VGTC conference 模板，正文最多 9 页，另允许 2 页仅含参考文献与致谢。
不通过缩小字体或边距腾出篇幅。

## 已直接落实到正文的修改

1. **摘要与引言**：先说明合并树地图的具体冲突，提前引入 CD-MTM，随后陈述贡献和证据范围。
   删除“所有静态摘要都受层级约束”的错误概括，避免把未经用户研究验证的读图行为写成事实。
2. **问题与目标**：新增 G1 诊断、G2 保留特征并量化合并层级变化、G3 披露实际误差三项目标，
   对应理论、方法和案例。明确 T1–T3 是设计任务，不是已验证的用户行为。
3. **方法结构**：按参考与诊断、松弛与优化、渲染与披露分成三个小节；区分证书下界、
   实际布局误差及拓扑成本。说明完整序列拟合参考方向属于离线分析。
4. **相关工作**：加入 ParkView 并说明问题差异：两棵有序树之间的交错可视化，
   与一棵树在空间参考布局下的失真分析。其他写作样本不因“仿照写法”而加入科学引用。
5. **实验协议**：明确现有地图、保留层级、松弛、排序打包和精确投影各自回答的比较问题；
   从主表删除 fixed-X 行，固定方向仅作为稳健性控制。保持原实验数值。
6. **数据语义**：拆分压力与火灾数据协议；将“真实低压中心”收敛为处理后扩展场中的局部极小值，
   避免暗示已经有独立气象真值。保留叶数与平滑选择对结论的影响。
7. **结果与讨论**：明确运动指标是几何代理；单列计算范围与复现性；讨论按任务选择视图，
   保留不显著、邻域质量下降和大拓扑代价等结果。删除早期径向/双轴探索对正式叙事的干扰。
8. **编译**：保留 pdfLaTeX 路径，增加 XeLaTeX/Tectonic 图片与 Times 字体兼容路径，
   修复 XeTeX 下仅识别 EPS 而找不到 PDF 图的问题。

## 仍影响录用的证据缺口，按优先级排序

| 优先级 | 审稿风险 | 下一步需要的具体证据 |
|---|---|---|
| P0 | ST-MTM 为自行复现，性能差异可能来自实现或参数 | 与原论文公式、公开示例和 Ring 参数逐项核对，列出适配与失败条件；如取得作者代码，再做一致性比较 |
| P0 | 提取协议控制叶数，可能决定冲突率和算法可运行性 | 在独立选定的平滑尺度、背景项与区域上做证书分析，报告失败和不可枚举情况；不能用可枚举性选择最佳数据后宣称普遍发生率 |
| P0 | 大规模证书被误读为整个算法大规模可运行 | 将证书、松弛、QP、填充和完整运行时间分别报告；完整算法只对实际测试规模作结论 |
| P1 | 参考方向与评估用同一批轨迹 | 增加前半序列拟合、后半评估或独立期间拟合的控制，并与固定参考对照 |
| P1 | 条带与见证叠加缺少实际阅读证据 | 若要主张读图收益，开展任务研究：分别测试投影运动判断和合并层级判断，比较有/无披露；不能把几何代理当作用户研究 |
| P1 | 代理阈值和不同真值对应不同事件集合 | 补充同一事件集合上的配对分析、病例数量与时间依赖处理；清楚区分 reversal、miss、combined error |
| P2 | 数学内容密集，审稿人难以快速把握适用范围 | 用一次完整的三特征例子贯穿证书、松弛、填充、实际成本；验证每条定义和图中符号对应 |
| P2 | 文献条目仍有不完整页码/DOI与预印本 | 投稿前做逐条来源核查并更新正式发表信息；特别核查最接近的 TMTM/ST-MTM 工作 |

本轮完成的是结构、表述和主张范围的修订，未增加参与者、未重跑真实数据实验，也未生成新的实验结论。
不能据此给出可信的录用概率数字。后续优先补齐 P0 证据，再决定是否需要用读图研究支持更强的应用主张。
