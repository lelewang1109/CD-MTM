# Paper package

`pacificvis2027/main.tex` is the anonymized conference manuscript and
`proofs.tex` contains the extended proofs. The venue directory also includes
all required VGTC style files, bibliography data, final figures, and the current
10-page review PDF (`review-preview.pdf`; pages 1–9 body, page 10 references).

The manuscript is self-contained. The code and result records needed for
reproducibility are organized at the repository root.
