# Final-paper result records

This directory contains the curated machine-readable records used by the
PacificVis manuscript. It excludes the historical dual-axis evaluation,
intermediate plots, and superseded `eval_v2.json` output.

`eval_projection.json` is the principal evaluation record. The remaining files
cover certificate scaling, exact frontiers and attainable fillings, extraction
sensitivity, baselines, witnesses, and the reported topological case study.
